# JUST BOUGHT IT

I sometimes feel excited about buying something, but after I buy it, I start wondering if I really wanted it. This made me think about the difference between wanting to buy something and wanting to own it. For this project, I wanted to make a shopping simulation where people could experience clicking Buy without actually spending money or receiving a product. I was curious whether that moment could give them some satisfaction, but I don't know if it would feel the same as a real purchase.

I used ChatGPT and Codex to help me turn this idea into HTML, CSS, and JavaScript. I wanted the page to feel like a simple fashion store, rather than starting with a questionnaire. After the simulated purchase, users answer a few questions and choose Let It Go, Save for Later, or Still Interested. One thing I wanted to keep was that the website should not decide for them. Sometimes we still want something even if we don't need it, and I wanted to leave room for that.

When I tested the earlier version, the shopping experience felt realistic to me, but the reflection questions felt too simple. They asked whether I still wanted the item without helping me think much about why. I asked AI to change the questions to focus on what I hoped the purchase would make me feel, whether I wanted the product or the excitement, and whether I would still want it a month later. These changes are in the code here, but I ran into a connection problem when trying to publish them, so the live website may still show the older version.

The JavaScript keeps the answers in three variables and uses if/else statements to show different reflection messages. This helped me understand how an idea about feelings becomes a set of choices and rules in code. It also made me notice what gets lost: choosing one answer doesn't capture everything someone feels, and imagining a purchase is different from actually paying for it. If I kept working on this, I would want to see whether the questions help someone understand their own reasons for wanting an item.

To run the project, download index.html, style.css, and script.js into the same folder, then open index.html in a browser. No installation is needed. Save for Later keeps the saved item in that browser when browser storage is available. No real payment or order happens.

Live prototype: https://just-bought-it.upbeat-bead-3953.chatgpt.site/
